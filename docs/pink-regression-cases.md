## macOS 执行约定

- 先确认实际运行的 PinK 版本、macOS 版本、引擎环境，以及实际加载的 Builder 和 L10N 插件身份。源码、缓存目录或插件安装清单不能代替实际运行身份。
- 使用可丢弃工程、临时目录或副本，保留源材料和其他任务改动。各用例记录初始状态，独立恢复，不依赖上一条留下的修改。
- 操作按界面实际标签进行。常用快捷键在 macOS 通常使用 Command，但以当前绑定为准；输入框内的撤销和场景撤销不能混同。优先使用明确的产品菜单或按钮。
- 浏览器预览指 PinK 对应入口；允许使用内置浏览器视图，不强制 Chrome。构建目标固定 web-desktop，通过真实面板提交；CLI 成功不能代替面板验证。
- 构建产物通过本地 HTTP 服务或产品提供的实际运行入口打开，不能把 file URL 失败直接归为产物缺陷。
- 不固定等待秒数。依据项目就绪、资源导入结束、任务终态及真实业务结果继续；超时需记录可观察状态。
- 检查保存、重开、预览和产物运行的证据分别记录。截图辅助判断，不能替代无法从画面确认的文件状态或配置结果。
- 用例失败时保留原预期。区分产品缺陷、功能未交付、用例问题、材料或环境阻塞，不直接删用例。
- 无法控制原有自动保存、语言偏好或权限等前置条件时，先记录阻塞。不要悄悄修改全局设置、清用户存储或借手动重导掩盖自动更新失败。

## 工程编辑与成果保存

### E01 基础编辑与保存重开

前置：已保存场景、普通节点及图片，无未保存修改。记录场景路径/UUID、父节点完整路径、图片/SpriteFrame UUID、初始属性及本条唯一名称，避免同名混淆。

1. 打开工程，初始化后核对工程与场景身份。
2. 新建 EditTarget，调整父子关系，核对层级与选择对象。
3. 添加 Sprite，设置 SpriteFrame 和明确位置，重命名后核对 Inspector 与显示。
4. 保存，关闭场景重开核对；再关闭工程、重开同一场景再次核对。两种重开分别记录。

预期：名称、父子关系、组件、位置、引用和图片显示与本条保存目标一致；其他原有内容未改。不能依靠业务脚本自动重建节点掩盖保存失败。两轮编辑问题的历史结果保留，不因复测通过覆盖原失败。

来源：层级 7、20、23；属性 19；PinK 保存重开合同。

### E02 撤销重做与保存

前置：已保存节点，路径/UUID明确；记录位置初值 A 与目标 B。优先产品菜单；输入提交后焦点回场景，保持目标选区，避免输入框逐字符撤销混入场景动作。

| 操作 | 当步预期 |
| --- | --- |
| 位置 A 改为 B | 场景与 Inspector 为 B |
| 删除节点 | 节点消失 |
| 撤销删除 | 节点、父子关系及位置 B 恢复 |
| 撤销属性修改 | 位置为 A；保持选区时 Inspector 立即同步 |
| 重做属性修改 | 位置为 B；保持选区时 Inspector 立即同步 |
| 重做删除 | 节点消失 |
| 再撤销删除，保存重开 | 节点存在且位置 B，关系与引用正确 |

每步独立记录，不能只检查最终保存。若选区被动作改变，记录并定位同一对象，不把其他节点的值当结果；不能靠切换选区刷新后才算即时同步。不固定内部 undo 数量。

来源：UNDO 4、6；PinK 操作分组。暂不含脚本更新、Prefab、动画引发的撤销。

### E03 新建工程与首次保存

前置：独立空目录，无需要保留的文件。

1. 从 PinK 创建项目入口选择空目录 pink-edit-smoke，完成创建及初始化。
2. 新建场景，添加普通节点，首次保存到工程内合法位置。
3. 关闭工程，重新打开工程和场景。

预期：项目身份、创建结果及场景正确；首次保存内容可再次打开。

当前已读入口按目录名命名、使用 3d 模板；手册中的 2D 类型选择及独立名称输入与之不一致。macOS 若显示相同入口，核对项目名 pink-edit-smoke 和 3d 类型；若入口不同，记录实际版本和差异，不套用 Windows 步骤，也不把 2D 选择缺失直接判失败。

来源：层级 40；PinK 创建项目资料及当前入口。类型和命名差异作为平台/版本校准项，不阻塞其他用例。

### E04 未保存修改保护

前置：已保存场景，属性为 A；没有场景自动保存干扰。三个分支分别恢复初态执行。

1. 改为 B，尝试关闭场景，选择取消。
2. 重新开始，改为 B，关闭时选择保存，重开。
3. 重新开始，改为 B，关闭时选择不保存/丢弃，重开。

预期：有明确未保存反馈；取消不关闭，B 留在未保存编辑状态；保存后重开为 B；不保存后重开为 A。按按钮语义判断，不固定文案。

来源：场景 61；PinK 关闭确认、保存与取消合同。首轮只关闭单个场景，不扩展关闭整个窗口或切换工程。

取消、保存、不保存三个分支各自记录初态、按钮语义、dirty/标签状态和重开值；分支不新增用例编号，任一未完成不得整条通过。

### E05 场景隔离

前置：场景 A、B 已保存，内容可区分。

1. 打开 A，选择并修改节点，保存。
2. 切换 B，修改并保存 B。
3. 分别关闭并重新打开 A、B。

预期：每个场景的内容、选择和 Inspector 正确；各自保留修改，不串写、串引用或相互覆盖。不额外要求切换后撤销历史必须清空或保留。

来源：场景 60；新增风险：选择及保存隔离。

### E06 复制后独立编辑

前置：普通父树含 Sprite 和已知属性，不使用 Prefab。记录原父/子节点完整路径或 UUID、子树初值及引用，准备唯一副本名称。

1. 复制父节点，对普通目标执行 Paste，核对副本在所选目标父级形成兄弟节点；不要混入 Paste as Child。
2. 改副本名，修改副本子节点位置，删除一个副本子节点；每步核对原树和原属性未变。
3. 保存，关闭场景重开；再关闭工程重开，分别核对原树、副本、属性和引用。

预期：副本结构与初始复制内容正确，副本修改不影响原节点；两种重开均保留最终状态。共享图片是正常资源引用，不当作节点错误关联；不固定自动名称后缀。

来源：层级 21、22；PinK 粘贴目标合同；副本独立性为新增风险。

### E07 变换工具与属性同步

前置：可见节点路径/UUID、X/Y/Z、旋转与缩放初值明确；填写拖动轴和随后输入的目标位置。工具与焦点正确，需要可靠人工接管真实拖轴。

1. 真实拖指定轴，记录拖前/拖后位置；轴上产生可观察位移，未操作分量、旋转和缩放保持。
2. Inspector 输入明确位置，画面与属性相符。
3. 撤销回输入前位置，再重做回目标值；每步观察同步。
4. 保存、关闭重开，核对最终变换。

拖轴、输入、撤销、重做、重开分别记录。输入未送达或未形成可靠位移证据记输入阻塞，不判 Gizmo 失效；仅属性输入通过不能替代拖轴。首轮仍以移动为代表。

来源：场景 4；补充保存重开检查。

### E08 组件删除与恢复

前置：普通节点带可删除 Sprite，记录全部代表属性、SpriteFrame UUID及显示，无组件依赖限制。

1. 移除：立即检查组件消失、对应显示变化及其他组件保持。
2. 撤销：立即检查组件、原属性和资源引用恢复。
3. 重做：立即检查再次删除；保存并关闭重开，检查最终仍删除。

每步单独记录，不能只看最终删除。预期仍为目标组件准确删除/恢复，其他内容不受影响。

来源：UNDO 8；PinK 移除入口；恢复数据完整性为新增风险。

### E09 多选批量编辑

前置：A 位置为 (10,0,7)，B 为 (20,0,9)，另有未选中 C。

1. 同时选择 A、B，只将 Y 改为 30。
2. 分别选中 A、B、C 检查。
3. 保存并重新打开。

预期：A 为 (10,30,7)，B 为 (20,30,9)；X、Z 差异保留，C 不变；重开一致。首轮覆盖基础位置属性，不宣称数组、事件及所有自定义属性都支持多选。

来源：层级 33、34；PinK 多选分量合并合同。

共同前置：输入保存、输出位置可区分；按本条适用阶段取证，不机械要求失败/取消任务拥有成功产物。L10N 使用目标随包插件，不安装旧 localization-editor。
